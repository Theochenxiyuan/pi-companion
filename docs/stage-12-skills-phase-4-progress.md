# 阶段 12：技能管理阶段 4 进展

> 历史实现记录：本文描述的技能库和工作区安装管理 Modal 后来已删除，不再代表当前产品边界。当前基线以 `docs/pi-companion-product-technical-plan.md` 第 8.8、16.6 和阶段 9 为准。

状态：**阶段 4“工作区管理已安装技能 Modal”已完成**

完成日期：2026-07-27

## 本阶段交付

### 复用的工作区技能 Modal

- 新增 `AppliedSkillsModal.vue`，直接消费阶段 1～3 已有的 `SkillsLoaded`、`ApplySkill` 和 `UnapplySkill` contract，没有建立第二套技能状态或新增 Bridge 协议。
- Modal 以工作区 ID 过滤真实发现快照：
  - 左侧按“工作区技能”和“全局技能”分组。
  - 工作区中的 Pi Companion 受管安装可以移除。
  - 外部工作区安装明确标记但不可由 Companion 删除。
  - 全局技能不显示操作按钮，并提供“管理全局技能”入口跳转技能主页。
- 右侧展示可滚动、可搜索的本地技能库，支持选择 Pi 专属或通用 Agent 目标并安装到当前工作区。
- 库中技能会明确标记：
  - 全局生效。
  - 已安装到当前工作区。
  - 已通过外部安装生效。
  - 目标冲突、不可访问或受管副本漂移。
- 可直接安装的技能不再显示重复的“可安装”状态，只保留安装按钮；未信任工作区仍要求独立二次确认 Pi 项目信任影响，不能通过快速入口绕过阶段 3 的安全边界。
- 技能主页不再重复显示库中技能数和文件总数；技能数保留在 Tab 徽标。常规搜索只匹配名称和描述，逐文件清单不再发送到前端或渲染，详情改为“打开文件夹”。
- 移除操作带二次确认，只移除当前工作区的受管副本，技能库原件和全局技能不变。
- 安装或卸载完成后继续使用 Host 返回的真实 `SkillsLoaded` 快照，左右两栏会同步刷新。

### 三个入口

- “全部任务”中的工作区更多菜单新增“管理已安装技能”。
- 工作区对话 topbar 新增“技能”按钮。
- 技能主页 topbar 新增“管理工作区技能”，可从已登记工作区列表打开同一个 Modal。
- 三个入口最终都只传递工作区 ID，由 `App.vue` 统一解析并打开同一组件，避免按入口维护不同状态。

### Direct Chat

- Direct Chat 的对话 topbar 使用同一个组件的简化模式。
- 简化视图只展示全局生效技能，并提供前往技能主页的入口。
- 不展示本地技能库的工作区安装操作，也不展示或修改 Direct Chat 的内部托管工作目录。

### 开发预览与响应式布局

- 新增开发模式预览入口 `?preview=skills-applied`，用于在没有桌面 WebView Bridge 时渲染阶段 4 Modal。
- 预览数据继续受 `import.meta.env.DEV` 保护，生产构建不会用预览状态替代 Host 快照。
- 宽窗口使用左右双栏；窄于 620px 时改为单列滚动，底部操作栏保持可见。
- 打开 Modal 时背景工作区设置为 `inert`，Escape 优先关闭内部确认层，再关闭 Modal。

### 生效技能只读访问与详情可读性

- Pi 运行上下文升级为 schema 3，只把当前任务实际生效的技能包注入 Extension：
  - 目录型 `SKILL.md` 技能只读开放其包目录。
  - Pi 全局根目录中的单文件技能只读开放该文件，不连带开放同级目录。
  - 工作区任务按工作区胜出结果注入；Direct Chat 只注入全局胜出结果。
- `read`、`grep`、`find`、`ls` 读取生效技能时不再弹出工作目录外授权。
- `edit`、`write` 仍被直接拦截；工作区内的技能包同样保持只读，符号链接或 junction 不能借技能目录逃逸。
- 已安装技能详情移除“Pi 原生全局优先项”；受管安装的“卸载”按钮与路径行右侧对齐。
- 技能库详情和已安装技能详情统一收窄到 560px；调用方式使用“模型自动 或 用户手动”。
- 安装路径由微型单行省略文本改为 13px 正常行高，并支持长路径自动换行。
- 详情只保留安装位置、调用方式、路径、诊断和可执行操作，不再展示解释数据来源或“优先级”的页脚文案。

### 文案减量

- 技能主页、已安装详情、扫描详情、安装/导入弹窗和工作区技能管理弹窗移除复述标题、按钮、布局和同步机制的说明。
- 设置页移除各分类页头说明、静态 Pi 项目信任说明，以及复述开关名称的辅助文字；安全边界、永久删除影响、数值语义和非显然限制继续保留。
- 占位页和重命名、编辑弹窗只保留完成操作所需的信息，删除重复的“功能将在后续版本提供”“输入名称”等提示。

## 严格未做

- Modal 不提供导入、删除库中技能、升级、迁移安装位置或管理来源。
- 不接管、覆盖或删除外部安装。
- 不为 Direct Chat 暴露或创建普通工作区技能目标。
- 不修改阶段 3 的安装、信任、运行任务阻止和 Pi worker 失效规则。
- Bridge protocol version 提升到 46，增加按技能包 ID 打开库中技能文件夹的桌面消息，并从技能库快照和导入预览中移除逐文件清单。
